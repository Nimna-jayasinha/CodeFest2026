# Skills Context

This folder stores supporting files that document the AI-assisted workflow used during the ByteKnights project.

## Purpose of this folder

The `skills` directory exists to preserve supporting material for the submission package and to make the AI usage trail easier to review.

## Contents

- [claude.md](claude.md) — structured summary of AI-assisted chat usage during project development
- [context.md](context.md) — explanation of the purpose and scope of this folder
- Additional project artifacts referenced by the summary, including the disclosure file in [ai_usage/ai-usage-disclosure.md](../ai_usage/ai-usage-disclosure.md)

## Intended use

These files support the mandatory AI usage disclosure by providing:

- a clear explanation of AI involvement
- a summary of the areas where AI assistance was used
- traceability back to project artifacts and repository evidence

## Relationship to the submission

The contents of this folder are intended to complement the formal disclosure and the repository documents, not replace them. The primary evidence remains the project code, documentation, and final submission PDF.
